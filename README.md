Entry for the [make.fun bounty](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3).

A small program that writes one sentence — a small moment of wonder in everyday life — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The program is deterministic: it always writes the same single sentence, validated to be 1–200 characters, one sentence, and UTF-8 text with no trailing newline.
